# 기존 엑셀 분석과 확장 기획

분석일: 2026-11-05 · 가칭: space-utilization · 상태: 분석 완료, 제안 검토 중

## 분석 방법과 범위

사용자가 지정한 작업 중 XLSX 원본을 읽기 전용으로 ZIP/XML 분석했다. 원본 복사·수정, Excel 실행, 수식 재계산, 외부 연결 갱신은 하지 않았다. 원본의 개인별 값·개인정보·전체 로컬 경로는 문서에 기록하지 않는다. 아래는 파일 구조와 수식에서 확인한 사실이며 실제 업무 절차는 사용자 확인이 필요하다.

## 확인한 구성

| 시트 | 확인한 내용 | 서비스에서의 역할 후보 |
| --- | --- | --- |
| 목록 | 별도 안내 시트 존재 | 시작 화면·화면 이동 |
| 감독교사 배정 | 공간별 감독 배정, 지정요일제 및 미운영일 예외에 관한 설명 | 담당자 배정·운영 예외 |
| 자습 불참 현황 조사 | 좌석번호·학번·이름·성별·자습실, 월~목 각 4개 시간대, 불참 사유 선택 목록 | 이용자·공간 배정·반복 불참 일정 |
| 일반실 출석부 | 일반 구분으로 원본을 FILTER/LET 조회, 날짜 증가 수식, 감독교사 영역 | 공간별 일자·시간대 운영표 |
| 정독실 출석부 | 정독 구분으로 원본을 FILTER/LET 조회, 날짜 증가 수식, 감독교사 영역 | 동일 기능의 다른 공간 보기 |
| 일반실 자리표 | 좌석과 공간 구분을 조건으로 이름을 XLOOKUP | 공간별 좌석 배치도 |
| 정독실 자리표 | 좌석과 공간 구분을 조건으로 이름을 XLOOKUP | 동일 기능의 다른 공간 보기 |

- 조사 시트는 월·화·수·목 × 8교시·야간1·야간2·야간3의 16칸 구조다. 금요일·주말의 필요 여부와 각 시간대의 실제 시작·종료 시각은 파일만으로 확정하지 않는다.
- 입력 목록은 가정·학력·체대·학원 등의 사유 코드를 제공한다. 코드 설명과 적용 정책은 확인이 필요하다.
- 조사 시트에 입력 목록 검증과 조건부 서식이 존재한다. 서식 색상을 실제 출결 상태라고 추정하지 않는다.
- 출석부에는 수식 기반 조회가 있으나 실제 출석 체크를 어떻게 수행하는지는 확인되지 않았다. 사전 불참 조사와 실제 결석은 서로 다른 정보로 설계한다.
- 좌석표는 좌석번호와 공간을 함께 조회한다. 기존 API의 전체 좌석번호 중복 검사와 차이가 있다. 공간별 번호 중복 허용 정책을 확인해야 한다.
- 조사 제목의 연도와 좌석표의 기간 안내 연도가 다르다. 오래된 양식 문구일 가능성은 있으나 단정하지 않는다. 운영 기간을 별도 설정으로 관리하는 근거로 삼는다.
- 외부 연결 XML 1개가 존재한다. 연결 대상은 접근·갱신하지 않았으며 실제 의존 여부는 미검증이다.
- 수식 개수는 출석부 각 5개, 자리표 각각 90개·14개다. 이 개수를 정원으로 해석하지 않는다. 캐시 결과의 최신성과 Excel 화면 배치는 미검증이다.

## 업무 흐름에 대한 해석

파일 구조에서 추론한 흐름은 운영 기간 설정 → 이용자·공간·좌석 등록 → 요일/시간대 불참 조사 → 공간별 출석부·좌석표 생성 → 감독자 배정·현장 확인이다. 이는 사용자에게 확인할 가설이다. 실제 출석 확인, 변경 승인, 조사 회수 방법은 아직 모른다.

## 권장 공통 뼈대

단순 학생 CRUD에서 공간·운영 일정·배정·예외 일정을 분리하는 방향을 제안한다. 범용 플러그인 엔진은 첫 버전에서 만들지 않는다.

| 모델 후보 | 책임 |
| --- | --- |
| 운영 기간 | 학기·차수·프로그램 등 시작/종료 기간 |
| 공간 / 이용 단위 | 공간 명칭, 좌석·작업대의 식별과 배치 위치 |
| 이용자 / 기간별 등록 | 공통 이용자 식별, 학교별 정보는 선택 속성, 기간별 참여 |
| 운영 시간대 | 요일·시작/종료 시각·표시명, 운영하지 않는 날짜 |
| 배정 | 이용자·공간·이용 단위·유효 기간 연결 |
| 이용 예외 | 반복 불참 규칙, 특정 날짜 예외, 사유 코드 |
| 담당자 배정 | 담당자·공간·운영 요일/시간대, 날짜별 변경 |
| 실제 이용 기록 | 날짜·시간대의 확인 상태, 사전 계획과 별도 보관 |

반복 규칙과 날짜 예외의 우선순위를 명시해야 한다. 빈칸·미조사·참여 예정·불참 예정·미확인·실제 출석/결석을 같은 값으로 합치지 않는다. 취소·변경 이력, 겹치는 배정 방지, 과거 기간 보존을 상세 설계에서 다룬다.

자습실 기본 설정은 학생 식별·고정석·교시·불참 조사·출석부, 작업실 설정은 팀·작업대·시간 예약 등으로 확장할 수 있다. 작업실 후보 기능은 이번 엑셀에서 확인된 요구가 아니며 후속 검토 대상이다.

## 단계별 확장안

| 단계 | 범위 | 완료 조건 후보 |
| --- | --- | --- |
| 1: 엑셀 업무 재현 | 운영 기간·공간·시간대·이용자·좌석 배정, 불참 일정, 공간별 운영표·좌석표·담당자 표시 | 합성 데이터로 원본 업무 구조 재현, 공간/기간 필터, 중복·예외 검증 |
| 2: 입력·배포 개선 | XLSX 가져오기 미리보기·검증·적용, 출력용 출석부/좌석표 | 실제 저장 전 오류·변경 내역 표시, 중복 가져오기 처리, 원본 보존, 사용자 출력 확인 |
| 3: 현장 운영 | 실제 출결·이용 기록, 날짜 예외·대체 담당자, 변경 이력 | 사전 일정과 실제 기록 구분, 과거 기록 보존·조회 |
| 4: 용도 확장 | 작업실 설정·팀 이용·시간 예약 | 확인된 실제 사례와 충돌 정책으로 검증 |

첫 버전 목표는 엑셀에서 검증된 업무를 화면에서 일관되게 관리하는 것이다. 엑셀 양방향 동기화, 자동 최적 좌석 배정, 무인 출결, 대외 공개, 범용 플러그인 플랫폼은 현재 범위로 확정하지 않는다.

## 첫 화면 구성 제안

운영 기간·공간 선택을 공통 필터로 두고, 이용자/배정, 주간 불참 일정, 날짜별 운영표, 좌석표, 담당자 배정, 설정 화면으로 나눈다. 기존 엑셀의 표 입력과 인쇄 흐름을 살리고 같은 데이터를 다시 입력하는 화면은 줄인다. 초기 접근 권한과 사유 노출 범위도 정해야 한다.

## 구현 전 확인할 질문

1. 불참 조사는 기간 동안 반복되는 주간 일정인가? 빈칸은 참여 예정인가, 미응답인가? 특정 날짜 변경은 어떻게 받는가?
2. 출석부는 출력해 수기로 확인하는가, 엑셀에 실제 결과를 입력하는가? 첫 버전은 어느 방식을 지원해야 하는가?
3. 좌석은 기간 고정인가? 공간마다 같은 번호를 쓸 수 있는가? 자리표의 물리적 배치를 그대로 유지해야 하는가?
4. 감독 배정·인쇄·XLSX 가져오기 중 첫 운영에 반드시 필요한 항목은 무엇인가? 운영 담당자만 입력하는가, 이용자 직접 제출도 필요한가?

이 질문의 답을 반영한 뒤 첫 구현 범위와 데이터 전환 방안을 확정한다. 기존 코드·DB는 이번 분석에서 변경하지 않았다.

## 후속 사용자 확인 — 2026-11-05

- 이 파일은 동료 교사에게 전달한 사용 양식이며 실제 참/불참 결과는 기록하지 않았다. 빈칸은 미응답일 수 있다. 파일의 입력 상태를 실제 참여/불참 데이터로 해석하지 않는다.
- 수기·엑셀 업무를 프로그램화하는 목적에는 타인의 편집으로 수식이 훼손되는 문제 방지가 포함된다.
- 좌석번호는 고정하고 이용자는 이동할 수 있으며 좌석 추가·제거가 발생한다. 좌석 관리 옵션화는 검토 중이다.
- PROJECT_PLAN.md에 좌석 식별/배정 분리, 공간별 좌석 사용 옵션, 입력/계산 규칙 분리 권고를 추가했다.
- 위 설명만으로 실제 출결의 디지털 입력 방식, 주간 일정 반복 정책, 공간 간 좌석번호 중복 정책까지 확정하지 않는다. 앞의 확인 질문은 이 답변을 우선 반영해 읽는다.
