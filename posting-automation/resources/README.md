# 포스팅 자료 준비 폴더

현재 자료를 보관할 위치만 준비했으며 자동 분석·업로드 기능은 아직 없습니다.

- `inbox/<자료이름>/`: 분석할 원고. 우선 Markdown(.md) 또는 UTF-8 텍스트(.txt)를 넣어 주세요.
- `reference-posts/`: 템플릿 참고용 대표 게시글 본문(.md/.txt) 또는 화면 캡처. 원문 URL도 함께 기록해 주세요.

비밀번호·토큰·개인정보가 담긴 자료는 넣지 마세요. 자료는 Git 추적에서 제외합니다. 파일을 넣는 것만으로 외부 전송이나 공개 발행을 실행하지 않습니다.
